## Syn3h v26.11.1515

Airborne human Jet flight returns to half throttle when the thrust controls are released.

Public release at 4:52pm Pacific on 15 November 2026, live at https://www.syn3h.com/.

### The story so far

The previous release added quality relief, camera update order and Jet tail lights. This release changes neutral flight thrust while preserving hover hold, vehicle-switch settling and automatic pilots. The README explains the updated controls.

### Features

- Human-controlled Jets use 50% neutral throttle in airborne flight. The Neutral flight throttle setting adjusts this value or disables it.
- Hold E or R for full thrust, and Q or F for reverse thrust in flight. Releasing the controls returns to the neutral setting. Hover mode keeps its existing upward/downward controls and altitude hold.

### Fixes

- Daydream explicitly marks its control ownership, so its deliberate zero-throttle commands stay zero. The marker clears when control returns to the player or the vehicle changes.
- Neutral flight thrust stays off while grounded, braking, paused, materializing, settling or inside a Zorb. Deliberate lift input can release settling suppression.
