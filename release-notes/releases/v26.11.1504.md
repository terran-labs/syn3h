## Syn3h v26.11.1504

Vehicle switching without a reload, a materialize cloud and Q and E for the jet.

Public release at 11:56am Pacific on 15 November 2026, live at https://www.syn3h.com/.

**Play this exact version: https://www.syn3h.com/?v=26.11.1504**

That link always serves v26.11.1504 as it was frozen at 11:52am Pacific on 15 November
2026, however many releases follow it. The plain address, https://www.syn3h.com/, serves
the latest build. The build frozen for judging is the one before this,
https://www.syn3h.com/?v=26.11.1503.

### The story so far

This release shipped four minutes before noon without the usual checks, on the owner's
order: merge everything that was open and cut one more release, and fall back if it breaks.
It was typechecked and built, and after deploy it passed the two-browser network check and
the frozen-version check on the public site. The unit suite, the release dry run and the
run-time asset check did not run. Treat everything below as merged and live, not as
individually verified.

It is also the first release made after frozen versions existed, so it is the first proof
that an earlier version keeps working: v26.11.1503 still serves its own files, byte for
byte, with this build live beside it.

### Features

**Vehicles**

Choosing another vehicle in play swaps it in place. The page no longer reloads, and bots
that were following you follow the new vehicle. The new vehicle arrives in a glowing cloud,
hovers for a moment and drops.

On a keyboard, E adds the jet's lift or thrust and Q takes it away. R and F still work.
Q and E no longer yaw the jet in flight; A and D bank it.

In Zorb mode a vehicle makes no engine noise and keeps its wings and gear tucked.

The tank is the Sherpa.

**Lobby**

A world beside the sun reads as a solid sphere, the galaxy rests at a lower viewing angle,
and each planet's orbit is sized by its world and ordered by temperature.

**Interface**

The panel header is rebuilt, and Leave world sits at the bottom of the panel. The logo
fades in.

### Play

Open https://www.syn3h.com/?v=26.11.1504 in a browser and tap a planet.
This exact version stays playable at https://www.syn3h.com/?v=26.11.1504, whatever ships after it.

- Change vehicle from the selector in play. It swaps where you are.
- Escape frees the cursor. A second Escape pauses.

### Known issues

- This release skipped the unit suite, the release dry run and the run-time asset check.
- The Buggy's new slide assist makes it run wide in hard, full-lock corners. Two tests
  were failing on it before this release.
- From just under the water at shallow angles, the sky looks too bright.
- Tag is still the default mode. The game mode list now offers Explore, but the room server
  does not know that mode yet, so choosing it is untested and may do nothing.
- A frozen version plays on the live room server, with players on the latest build. An
  invite or QR link made in a frozen version opens the latest build, not that version.
