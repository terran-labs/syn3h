## Mira v26.11.2711

### Features

The sidebar has one full-height resize handle.

### Fixes

Opening a card or moving the pointer between cards keeps the handle the same length.

### Handling

This release changes the sidebar interface.

### Play

Drag the sidebar edge to set its width. With the handle focused, the arrow keys adjust the width and Enter restores the default.

### Performance

The browser sizes the handle with the sidebar. Moving the pointer between cards no longer measures their positions.

### Known issues

Phones use a full panel with no resize handle.
