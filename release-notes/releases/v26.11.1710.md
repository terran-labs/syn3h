## Syn3h v26.11.1710

Bots stay put when the host's connection drops for a moment.

Public release at 6:00pm Pacific on 17 November 2026, live at https://www.syn3h.com/.

### The story so far

Players saw every bot in a room leave and a fresh set join, over and over. The cause was the host's own connection: when it dropped for a moment and came back, the game cleared the host's bots and built a new fleet. Now a host whose connection drops keeps its bots, with the same names, until the room says who hosts. If the room handed hosting to someone else meanwhile, the old bots go as before.

### Features

- After a reconnect, the game tells the room what the browser saw when the connection dropped (the close code, timings, whether the page was hidden, and the longest recent frame). Only numbers and fixed words are sent, never names or anything typed. This shows why connections drop.

### Fixes

- Bots no longer all leave and rejoin when the host's connection drops for a moment. They keep driving with the same names through the reconnect.

### Handling

No handling changes in this release.

### Play

Open https://www.syn3h.com/ with bots in the room and play for a while: the bots should stay the same bots.

This exact version stays playable at https://www.syn3h.com/?v=26.11.1710, whatever ships after it.

### Performance

Not measured for this release.

### Known issues

- Connections to the room still drop now and then; this release keeps the bots through it and records why it happens, so the cause can be fixed next.
- On a phone held sideways, the jet's throttle-down button overlaps the navigation buttons. The fix is on the touch controls branch.
- On an iPad, the navigation buttons overlap the King of the Hill winner announcement.
- Sound on a real iPhone in silent mode is unconfirmed until the owner tries it.
- Chat's word filter is short and English only.
