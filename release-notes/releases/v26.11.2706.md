## Mira v26.11.2706

### Features

Room hosts can manage bots in public worlds. Open Players to adjust the bot count or select a bot to edit its personality or remove it.

### Fixes

Bot count changes now require the current host even when world sliders are unlocked. The bot panel updates its controls when hosting changes hands.

### Handling

This change concerns room permissions.

### Play

Use the plus and minus buttons beside Bots in the Players card. Select a bot’s name for its individual controls.

### Performance

The room checks the host identity when a bot management request arrives.

### Known issues

The device’s quality budget can still limit the number of bots simulated.
