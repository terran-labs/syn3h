## Mira v26.11.2709

### Features

The upper-left HUD puts each shortcut before its label.

### Fixes

Gear numbers, SP, X and Y line up by their centers. Gear rows sit a little farther apart on desktop and touch screens.

### Handling

The bindings still use Space for Wings or Flight, X for Zorb and Y for Chat.

### Play

The circle beside the selected gear shows which gear is active.

### Performance

CSS positions the keycaps and spaces the rows.

### Known issues

None identified for this change.
