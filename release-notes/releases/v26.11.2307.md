## Mira v26.11.2307

Quality changes no longer leave graphics objects behind.

Public release at 9:00pm Pacific on 23 November 2026, live at https://mira.cc/.

### The story so far

Each time the game changed its quality level, it left the old level's sea, ground and other rebuilt pieces in graphics memory for the rest of the visit. On a phone that changes level often, that kept growing. They are now let go a few frames after each change, while everything the next climb needs is kept.

### Features

No new features in this release.

### Fixes

- Changing quality level no longer leaves graphics objects behind; on a phone that changes level often this had grown without limit.

### Handling

No handling changes in this release.

### Play

Open https://mira.cc/ and play as usual.

This exact version stays playable at https://mira.cc/?v=26.11.2307, whatever ships after it.

### Performance

Over ten quality cycles at phone size on Medium with WebGPU, live graphics objects held at 567 to 587 in our check, where before they grew from 751 to 2,293.
