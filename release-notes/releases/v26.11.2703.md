## Mira v26.11.2703

### Features

This beta restores Firefox audio compatibility.

### Fixes

Music and vehicle audio can hold their current volume during a fade on browsers that lack the native Web Audio method. This fixes an exception when sound starts, when a driver enters or leaves the Zorb, and when a remote engine fades out.

### Handling

Vehicle physics uses the same settings as the previous beta.

### Play

Press a key or tap the lobby to start sound. The engine fades out when you enter the Zorb and returns when you leave it.

### Performance

The fallback reads the current gain when a fade changes direction.

### Known issues

The Firefox check ran on macOS. The original report came from Windows 10 ESR.
