## Mira v26.11.2403

The physics engine retries a failed download, and the counter box fits a small phone.

Public release at 8:12pm Pacific on 24 November 2026, live at https://mira.cc/.

### The story so far

If the physics engine's download failed, the game used to stop at a message asking for a reload. The owner asked for it to retry by itself. Separately, the counter box the owner reads on his iPhone ran past its own edge on a phone and, on a small one, over the controls.

### Features

No new features in this release.

### Fixes

- If the physics engine fails to download, the game now tries again by itself.
- The counter box fits a phone screen: every line stays inside it, and it keeps clear of the controls.

### Handling

No handling changes in this release.

### Play

Open https://mira.cc/ and play as usual.

This exact version stays playable at https://mira.cc/?v=26.11.2403, whatever ships after it.

### Performance

No performance changes in this release. The physics engine still loads as one file, compiled as it streams.
