## Syn3h v26.11.1706

Reconnecting after a dropped connection no longer depends on the rest of the page behaving.

Public release at 11:01am Pacific on 17 November 2026, live at https://www.syn3h.com/.

### The story so far

When a connection dropped, the game tidied up the other players before trying to reconnect. If anything went wrong in that tidying, the attempt to reconnect never started, and the player sat disconnected until they reloaded the page. A test machine with an unreliable graphics device showed it every time. Now the reconnect is scheduled first and nothing in the clean-up can stop it.

### Features

No new features in this release.

### Fixes

- A player whose page runs into an error while disconnecting now reconnects, instead of sitting disconnected until a reload.
- Every line the room server records now names its room by its short tag, including after the server has paused a quiet room.

### Handling

No handling changes in this release.

### Play

Open https://www.syn3h.com/ in a browser and play as usual.

This exact version stays playable at https://www.syn3h.com/?v=26.11.1706, whatever ships after it.

### Performance

Not measured for this release.

### Known issues

- On some machines whose graphics device is lost, the page keeps reporting graphics errors; a fix is in progress.
- Players on an older build in the same room still see the old long names for the same bots.
- Planets between the three old sizes look wrong to players on frozen older versions.
- Chat's word filter is short and English only.
- Touch aiming was tested with simulated touches in a phone-sized browser, not yet on a physical phone.
