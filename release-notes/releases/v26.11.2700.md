## Mira v26.11.2700

### Features

This beta updates the Liquid sidebar.

### Fixes

Game, Players, World, Settings and Chat now follow the same Tint setting as Search. Opening a card keeps its tint.

### Handling

Vehicle handling is unchanged.

### Play

Choose Liquid in Settings and open a sidebar card. Adjust Tint to change the glass over the world.

### Performance

Scrolling cards use a CSS backing that moves with the panel. Frame cost was not measured for this change.

### Known issues

The existing iPhone graphics issues remain open.
