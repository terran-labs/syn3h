## Syn3h v26.11.1702

The buggy is now generated in code: no model to download, so it is ready sooner.

Public release at 6:00am Pacific on 17 November 2026, live at https://www.syn3h.com/.

### The story so far

Until now the buggy arrived as a downloaded 3D model, about 140 KB compressed and fetched on every start, and its arrival waited for that download. Now the buggy is built in code from a sculpted cage and fitted parts, the way the terrain, sky and sounds already are. It is ready on the first frame it is asked for, every part can follow its settings, and the game no longer loads a single model file in ordinary play.

### Features

- The buggy is generated in code: a cage-subdivided body with fitted parts, including the duct headlight lenses, the bow-tie stator, the canopy's rear edge, the wing tips, the tail lamps, and the shoulder line, haunch and fins along its flanks.
- Wings, the Zorb, the tyre size slider and other players' buggies all use the generated buggy.
- No vehicle model is loaded in ordinary play; the original models are kept as source material outside the game.

### Fixes

- The buggy no longer waits for a model download before it appears. In the builder's measurements in a desktop browser, from opening the page to the buggy showing took 0.7 s instead of 2.5 s, and 2.6 s instead of 5.5 s with the processor slowed six times as a stand-in for a phone.

### Handling

No handling changes in this release.

### Play

Open https://www.syn3h.com/ in a browser, tap a world, and look round the buggy: open the wings, press X for the Zorb, and try the Tyre size slider at both ends.

This exact version stays playable at https://www.syn3h.com/?v=26.11.1702, whatever ships after it.

### Performance

Measured on this release's production build against v26.11.1701: 37 files instead of 43 and 7.5 MB instead of 8.3 MB, with no model files. The main script grew by 14.7 KB compressed, since it now carries the buggy generator. On the builder's runs the first load until the buggy shows was 292 KB smaller compressed, the two buggy models plus a smaller game chunk. Near the camera the buggy draws 11,490 triangles in 6 draws.

### Known issues

- The original tank models are no longer viewable anywhere in the game or the vehicle lab; the files remain as source material.
- Players on an older build in the same room still see the old long names for the same bots.
- Planets between the three old sizes look wrong to players on frozen older versions.
- Chat's word filter is short and English only.
- Touch aiming was tested with simulated touches in a phone-sized browser, not yet on a physical phone.
