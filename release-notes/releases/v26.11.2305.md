## Mira v26.11.2305

Sun shadows off on iPhone and other touch devices for now, and clearer word when the graphics process stops.

Public release at 9:00pm Pacific on 23 November 2026, live at https://mira.cc/.

### The story so far

On iPhone, iPad and other touch devices using WebGPU, sun shadows were behind the whole-screen black flashes, so they are off on those devices for now, with a link to turn them back on. When a phone's graphics process stops, the game now says so plainly instead of naming a cause it cannot know, and Diagnostics keeps a record of it across the reload, so a report sent afterwards still shows what happened.

### Features

- Diagnostic links are documented in the README and stay in every release.

### Fixes

- On iPhone, iPad and other touch devices using WebGPU, sun shadows are off for now. They caused whole-screen black flashes in Safari. Add ?shadows=1 to the address to turn them back on.
- If the graphics process stops, the notice now says so plainly, and Diagnostics keeps a record of it across the reload.

### Handling

No handling changes in this release.

### Play

Open https://mira.cc/ and play as usual.

This exact version stays playable at https://mira.cc/?v=26.11.2305, whatever ships after it.

### Performance

No performance changes in this release.
