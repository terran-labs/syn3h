## Syn3h v26.11.1707

Sound on iPhones in silent mode, a clean lobby name after turning a phone, and a plain message when graphics fail.

Public release at 11:00am Pacific on 17 November 2026, live at https://www.syn3h.com/.

### The story so far

An iPhone with its ring switch set to silent kept the game mute. The game now asks for sound the way a music player does, and offers a tap to start it when the phone holds it back. Turning a phone from landscape to portrait could leave a pale box where the Syn3h name should be; the name now redraws cleanly. And when a computer's graphics device is lost, the game says so once and offers a reload, instead of failing quietly over and over.

### Features

- iPhone sound: the game plays with the ring/silent switch on silent, as a music app does. A new Sound setting, "Play when the phone is on silent" (on by default), turns this off. While it is on, the game pauses music playing in other apps. This has not yet been confirmed on a real iPhone.
- "Tap to start sound" appears whenever the browser is holding the game's sound back, and a tap brings the music and effects back.

### Fixes

- The Syn3h name in the lobby no longer turns into a pale box after a phone is turned from landscape to portrait.
- The lobby's sun sits in the centre on short landscape screens, as it does in portrait.
- If the graphics device is lost, the game now says so once and offers a reload, instead of erroring silently every frame.

### Handling

No handling changes in this release.

### Play

Open https://www.syn3h.com/ on a phone, turn it between portrait and landscape in the lobby, and on an iPhone try the game with the ring switch on silent.

This exact version stays playable at https://www.syn3h.com/?v=26.11.1707, whatever ships after it.

### Performance

Not measured for this release.

### Known issues

- Sound on a real iPhone in silent mode is unconfirmed until the owner tries it.
- Players on an older build in the same room still see the old long names for the same bots.
- Planets between the three old sizes look wrong to players on frozen older versions.
- Chat's word filter is short and English only.
- Touch aiming was tested with simulated touches in a phone-sized browser, not yet on a physical phone.
