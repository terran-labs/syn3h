## Mira v26.11.2704

### Features

The full-resolution Mira name keeps its existing placement and appearance.

### Fixes

The wordmark and its distance field used to compile shaders inside the galaxy draw loop. The lobby now prepares both programs during setup.

### Handling

This release changes lobby rendering only.

### Play

Open Updates, close it, and open it again.

### Performance

Reopening Updates reuses the programs prepared for the lobby. Enabling full-resolution letters through Settings prepares their shaders when the setting changes.

### Known issues

The original phone freeze did not recur in the baseline check.
