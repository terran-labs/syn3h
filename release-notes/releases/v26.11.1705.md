## Syn3h v26.11.1705

The room server keeps a record of connections and modes, to find faults faster.

Public release at 9:00am Pacific on 17 November 2026, live at https://www.syn3h.com/.

### The story so far

Nothing in the game looks or plays differently. Behind it, the room server now writes a short line when a player connects, leaves, loses a connection and comes back, and when a room changes mode or a hill is taken. When something goes wrong in a room, those lines show what the server saw. They hold no names, no chat and no room names, and they are kept for seven days.

### Features

No new features in this release.

### Fixes

- The room server records connection and mode events, without names or chat, so faults can be diagnosed from what the server saw instead of guessed at.

### Handling

No handling changes in this release.

### Play

Open https://www.syn3h.com/ in a browser and play as usual.

This exact version stays playable at https://www.syn3h.com/?v=26.11.1705, whatever ships after it.

### Performance

Not measured for this release.

### Known issues

- Players on an older build in the same room still see the old long names for the same bots.
- Planets between the three old sizes look wrong to players on frozen older versions.
- Chat's word filter is short and English only.
- Touch aiming was tested with simulated touches in a phone-sized browser, not yet on a physical phone.
