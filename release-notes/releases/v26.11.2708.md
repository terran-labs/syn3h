## Mira v26.11.2708

### Features

Scroll fades show which direction has more content in panels, Chat and lobby sheets.

### Fixes

The first and last items are clear when you reach them. The panel name list stays clear all the way to the bottom in landscape.

### Handling

This release changes the interface.

### Play

Open a long list or conversation and scroll. Each fade disappears when you reach its edge.

### Performance

Scroll and resize events queue fade updates for the next frame. Lists that fit need no mask.

### Known issues

None identified for this change.
