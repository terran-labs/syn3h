This removal restores browser defaults rather than suppressing background behavior. Headless behavior remains distinct from physical OS windows.

Install passive bounded blur/focus/pagehide/visibility/pointer-lock observations on both contexts before either game entry. After both entries, arm sticky failures for loss of required active state, true window blur, pagehide, pointer-lock errors or retained-cord changes. ## Exact native sequence

1. Enter both actual app worlds by a native click on the current planet. If entry captured the canvas, release only an observed existing lock with one native Escape. Establish both connected, visible, focused, unpaused and unsuspended, with exact source/module evidence.
2. Without firing any weapon, exercise A, then B, then A: bring that browser page to front, use one ordinary first-capture canvas click, require actual canvas lock, then one native Escape and require unlocked/unpaused Inspector readiness. Require both peers active and ticking at every boundary. Total projectile shots and Grapple launches remain zero. A failure here prevents all attachment work.
3. For A, capture through the same native path, select Digit4, move the native mouse once from canvas centre toward `(640,770)` in twelve steps, and inspect actual read-only `aimFrom`. Require selected Grapple, effective reach300, a fixed-ground hit within reach and beyond5m, neutral fire and zero earlier launches. 4. Repeat that one attachment attempt for B. A's existing cord must survive throughout. Both peer inventories must identify both owners and their ground anchors. The TS-private Bungee cord map is read only. Local full-precision coordinates are compared with the exact centimetre rounding used by Bungee's wire format on the other peer; subsequent stability uses each peer's own recorded representation. No count-only or arbitrary-distance assertion substitutes.
5. Put B into the control position a future native shot would use: recapture, select normal Plasma Tag with Digit1, move the mouse back to `(640,450)` once, require lock and neutral fire, then Escape. Do not fire. Both cords must survive the selection and transfer. This camera movement proves only control reachability, not a safe projectile trajectory.

Native input means Playwright's browser mouse/keyboard route, not synthesized DOM events or physical hardware.
