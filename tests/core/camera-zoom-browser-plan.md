## Four bounded cases

One fresh Chrome desktop context, viewport 1280 by 900, normal shared-world entry
`alpine.1~bots.count=0`, unique dedicated room, default rendering settings. Capture
entry URL and actual effective camera parameters, connection, tick, selected gear,
suspension, pointer lock and scalar cord state. No parameter writes through private APIs.
All numeric setup uses the real Inspector search and editable number controls.

1. **Native pixel wheel and Inspector speed.** At distance 10 and default speed 0.4,
   native delta 100 gives 10.4, -25 gives 10.3, 5000 gives 10.7. Set speed 0.8 through
   the Inspector, assert next event adds 0.8. Exercise both distance clamps, then native
   Equal and Minus change distance by 1.6. Unlocked canvas targeting is verified with
   elementFromPoint; no forced wheel delivery through an overlay.
2. **Scope, roam and right-button toggle.** Hold native Z, verify scope alone changes
   by -0.25. Release Z and use native C four times to roam; delta 25 changes roam speed
   by 0.25 alone. Return to chase and exercise the supported native right-button toggle.
3. **Separately labelled synthetic normalization and pause.** Synthetic line/page
   half-units preserve the same formula. Native Pause followed by Equal must leave
   distance unchanged. The veil prevents native canvas targeting while paused, so an
   explicitly synthetic canvas wheel documents the current unguarded handler behavior.
   It does not establish native wheel reachability through the veil. Resume through
   the actual veil. No new suspension policy is asserted or implemented.
4. **Normal Grapple attachment and release positive.** Use native C to orbit, canvas
   click to capture, native gear digit, downward mouse look and one L press to launch.
   Require actual locked camera aim and an attached local cord with anchor or target.
   Native wheel down increases rest length; wheel up decreases it, while distance,
   scope and roam values remain unchanged in event and later state records. Native G
   releases the cord; the next native wheel must zoom again. No manual zoom/launch,
   private cord seeding, teleport, held input mutation, or retry after failed attachment.

Wheel observation uses the existing canvas handler order for ordinary zoom, and a
window capture observer after Bungee for intercepted events. It never calls or replaces
camera or Grapple control methods. Pixel records assert `isTrusted` and deltaMode zero.
